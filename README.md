# Калькулятор стоимости ведения Авито — Aveasy (внутренний)

Рабочий инструмент агентства: https://pianist13r.github.io/aveasy-calc/

На странице видно всё, из чего складывается цена — себестоимость по строкам (часы × ставка роли,
кол-во × ₽ за объявление), маржа, сработавшие минимумы и рыночные потолки, а также параметры
модели (ставки, целевая маржа, минимумы, часы по видам работ). Параметры можно менять прямо
на странице — режим «что если»; правки живут только во вкладке, прайс не меняется.

**Две выгрузки картинкой** (открываются прямо в Telegram):
- «Скачать внутренний расчёт» / «Копировать картинку» — с себестоимостью и маржой, для своих;
- «Выгрузить для клиента» / «Копировать КП» — коммерческое предложение без себестоимости,
  часов, ставок и маржи: первый платёж (настройка + первый месяц) и далее ежемесячно.

Клиенту отправляется выгрузка, а не ссылка: страница публична (GitHub Pages) и закрыта только
от индексации (`noindex` + `robots.txt`) — это не защита.

## Откуда берётся этот файл

`index.html` собирается из репозитория Aveasy и **вручную не правится**:

```
cd C:\Projects\Aveasy\core\pricing
node build-internal-page.mjs
```

Источник правды по ценам — `C:\Projects\Aveasy\core\pricing\config\pricing.config.js`.
После правки прайса: пересобрать, закоммитить и запушить этот репозиторий — Pages обновится сам.
Подробности — `C:\Projects\Aveasy\core\pricing\README.md`, раздел «Внутренняя страница для коллег».
